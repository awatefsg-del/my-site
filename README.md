# Teacher Courses — تمكّني | التطوير المهني للمعلمة

موقع عربي للتطوير المهني للمعلمة: دورات حديثة، مسار مهني، واختبار تفاعلي للمهارات.
يدعم الوضع الليلي/النهاري وتكبير/تصغير الخط، بخط Tajawal وزن 800 للعناوين.

## الصفحات
- `index.html` — موقع المقررات (الرئيسية)
- `tadweer.html` — منصة التطوير المهني للمعلمة

## النشر على GitHub Pages
1. ارفعي هذا المجلد إلى مستودع GitHub باسم `teacher-courses`
2. من صفحة المستودع: Settings ثم Pages
3. اختاري: Deploy from a branch ثم Branch: `main` و `/ (root)` ثم Save
4. الرابط سيكون: `https://USERNAME.github.io/teacher-courses/tadweer.html`

## التشغيل محلياً
افتحي `tadweer.html` في المتصفح مباشرة، أو شغّلي أي سيرفر محلي.
